# Software Rules

This repository follows the account-wide software rules maintained in `karpuzikov/userscripts/SOFTWARE_RULES.md`.

## UXDT baseline

The complete UXDT Guidelines tree at `https://www.uxdt.nic.in/guidelines/`, including all nested sections and subpages, is the mandatory UI/UX reference baseline for all current and future user-facing software in this repository.

Apply the relevant guidance in a platform-appropriate way, including usability, learnability, accessibility, keyboard/focus behavior, readable contrast and typography, color-independent status cues, clear navigation and forms, error prevention/recovery, user control, responsive/adaptive layout, visible progress/feedback, performance, consistency, testing, and iterative improvement.

When exact or current guidance matters, re-check the relevant UXDT subpage before implementation. Existing interfaces are not considered UX-finished merely because they predate this rule; when they are updated, audit and improve the relevant UI against UXDT before considering the update ready for testing.

Repository-specific behavior and functional requirements must be preserved unless the user explicitly requests a behavior change.
